### 제작 목표와 새 구역

교수자의 W06 산업단지 배경을 그대로 사용한다. 지형·건물·소품·조명을 유지한 채 수업 위치 (-125, 0, 315)에서 동쪽 약 50 m 떨어진 컨테이너 앞마당 (-75, 0, 310)에 세 표적을 배치했다. 원본 배경 14개 루트, 3,113개 Transform의 위치·회전·크기를 보존했다.

| 대상 | 표현 | 선택한 이유 |
| --- | --- | --- |
| 금속 | 스파크 + 작은 탄흔 | 밝고 빠른 반응으로 단단한 표면을 구분한다. |
| 목재 | 긴 나무 조각 + 불씨 디졸브 + 탄흔 | 길쭉한 실루엣과 타는 가장자리로 목재의 결을 표현한다. |
| 콘크리트 | 굵고 무거운 회색 파편 + 큰 탄흔 | 목재와 다른 조각 SG·VFX 값을 사용해 무게감과 부스러짐을 구분한다. |

Unity 6000.3.23f1에서 프로젝트를 열고, Project 창의 Assets > W06_HW > W06_HW 씬을 연다. Play를 시작하면 수업용 총이 자동 장착된다.

| R / F6 / Esc | 탄흔 지우기 / 자동 시연 / 커서 해제 | 비교 장면을 정리하거나 세 재질의 반응을 순서대로 본다. |

01 / WOOD

## 조각의 모양과 타는 시간

셰이더가 입자 하나의 윤곽을, VFX Graph가 개수·속도·수명을 결정한다.

SG_WoodChip_HW와 VFX_HitWood_HW를 과제 폴더에 복사해 독립적으로 조정했다. Simple Noise와 원형 마스크의 Multiply 결과를 Alpha에 사용하고, 입자 나이 비율을 Dissolve_Amount에 연결한다.

| 항목 | 설정값 | 기대 효과 |
| --- | --- | --- |
| SG / Noise Scale | 4.2 | 크게 뭉친 얼룩으로 목재 조각의 윤곽을 만든다. |
| SG / Alpha Clip 시작 | 0.16 | 밝은 노이즈 조각만 남겨 둥근 외곽을 끊는다. |
| 디졸브 연결 | Age Over Lifetime -> Dissolve_Amount | 개별 입자의 수명에 따라 잘려 나가는 범위가 커진다. |
| 파편색 / 가장자리 | 갈색 RGB (0.30, 0.105, 0.026)<br>주황 HDR 2.4 / 폭 0.035 | 갈색 중심과 좁은 불씨 띠를 구분한다. |
| Spawn | 단발 Count 27<br>Loop Duration 1 / Count 1 | 짧은 충격 한 번에 여러 조각이 퍼진다. |
| Capacity / Bounds | 96 / Manual, 크기 (7, 7, 7) | 여유 입자 수와 이동 영역을 확보한다. |
| 수명 | 0.90-1.45초 | 타들어 가는 변화를 볼 시간을 준다. |
| Size / Scale | 0.065 / (0.55, 1.70, 1) | 잘려 나온 긴 나뭇조각이 보일 크기를 확보한다. |
| Initialize / angleZ | Uniform Random 0-360도 | 파편마다 각도를 달리해 반복되는 모양을 줄인다. |
| 초기 방향 / 속도 | 로컬 위쪽 / 2.8-5.8 | 충돌 표면 바깥쪽으로 비교적 가볍게 튄다. |
| 중력 / Drag | (0, -10.8, 0) / 0.65 | 상승 뒤 낙하하는 곡선을 만든다. |
| 액터 생성 수명 | 3초 / Align To Surface 켬 | 그래프 수명보다 오래 프리팹을 유지하고 표면 방향에 맞춘다. |

### 값을 고른 이유

초기 시연에서 낮은 Clip 값이 매끈한 타원 외곽을 남겼다. 기준값을 0.16으로 올려 불규칙한 부분을 분리하고, 줄어든 윤곽이 보이도록 Size를 0.065로 키웠다. 무작위 각도와 긴 비율, 27개의 단발 입자로 목재의 가벼운 흩어짐을 설계했다.

02 / CONCRETE + METAL

## 재질에 따라 다른 충격

콘크리트는 목재 SG와 VFX의 복사본을 각각 바꿨다. 색상만 바꾸는 방식으로 끝내지 않았다.

| 항목 | 콘크리트 설정값 | 목재와 다른 기대 효과 |
| --- | --- | --- |
| SG / Noise Scale | 9 | 더 잘게 끊어진 불규칙한 돌 윤곽. |
| SG / Alpha Clip 시작 | 0.26 | 원형 외곽 대신 분리된 돌 부스러기 윤곽. |
| 디졸브 | 나이 연결 해제 / Amount 0 | 시간에 따라 타는 표현을 사용하지 않는다. |
| 파편색 / 가장자리 | RGB (0.36, 0.39, 0.41)<br>파편색과 동일한 일반 색상 | 회색 파편에 목재의 주황 발광이 섞이지 않는다. |
| Spawn / Capacity | 단발 Count 16 / 64<br>Loop Duration 1 / Count 1 | 큰 조각이 적게 튀는 반응. |
| Bounds | Manual / 크기 (7, 7, 7) | 설정한 이동 범위를 포함한다. |
| 수명 | 0.55-0.85초 | 목재보다 짧고 빠르게 정리되는 충격. |
| Size / Scale | 0.105 / (1, 0.80, 1) | 목재보다 굵고 덩어리진 조각. |
| Initialize / angleZ | Uniform Random 0-360도 | 고정 방향의 점 모양 반복을 줄인다. |
| 초기 속도 | 1.5-3.8 | 더 좁고 둔하게 퍼지는 파편. |
| 중력 / Drag | (0, -13, 0) / 1.15 | 더 무겁게 가라앉는 움직임. |

### 금속 표적

금속 피탄은 W05의 VFX_HitMetal_Spark를 FX_HW_Metal로 복사해 그래프 내부 수치를 유지했다. 세 표적 표면은 모두 URP Lit으로 구성했다.

| 항목 | 설정값 | 기대 효과 |
| --- | --- | --- |
| 금속 표면 | RGB (0.23, 0.31, 0.36)<br>Metallic 0.92 / Smoothness 0.67 | 차가운 강철색과 매끈한 반사. |
| 목재 표면 | 제공 목재 텍스처 x RGB (0.52, 0.30, 0.13)<br>Metallic 0 / Smoothness 0.16 | 목재의 결을 보존하고 반짝임을 낮춤. |
| 콘크리트 표면 | 제공 Rough + Normal<br>RGB (0.70, 0.72, 0.74)<br>Tiling (2,1) / Normal 0.38 | Wall_Concrete_Rough 텍스처와 노멀로 돌의 거친 표면 표현.<br>Metallic 0.03 / Smoothness 0.18. |
| 피탄 프리팹 유지 | 세 재질 모두 3초 | 짧은 파편·스파크가 끝난 뒤 생성물을 정리. |

값을 고른 이유: 초기의 점처럼 보이는 외곽을 줄이려고 Clip을 0.26, Size를 0.105로 높였다. 큰 조각, 느린 속도, 짧은 수명, 강한 중력·저항으로 목재와 실루엣·리듬을 구분했다.

03 / TRAIL + DECAL

## 지나간 자리와 맞은 자리

총알의 이동은 가는 빛으로, 표면의 충격은 재질별 크기가 다른 탄흔으로 남긴다.

| 항목 | 설정값 | 기대 효과 |
| --- | --- | --- |
| 총알 속도 / 발사 방식 | 32 / Single, 클릭당 1발<br>모드 전환 끔 | 입력 한 번에 겹치는 총알이 생기는 것을 막는다. |
| Trail Time / Width | 0.22초 / 0.035 | 표적을 가리지 않는 짧고 가는 궤적. |
| Trail 폭 커브 | 시작 1 -> 끝 0 | 꼬리 끝이 가늘어짐. |
| Trail 색·Alpha | 밝은 노랑 -> 주황<br>Alpha 1 -> 0 | 이동 뒤쪽으로 자연스럽게 사라짐. |
| Min Vertex Distance | 0.05 | 리본 궤적을 촘촘하게 연결. |
| Trail 머티리얼 | 제공 Mat_Trail 복사<br>Base Color (3.2, 2.45, 0.8) | 따뜻한 발광색과 Bloom의 번짐. |
| 금속 탄흔 W x H | 0.13 x 0.13 | 작고 집중된 자국. |
| 목재 탄흔 W x H | 0.17 x 0.22 | 세로로 약간 긴 목재 자국. |
| 콘크리트 탄흔 W x H | 0.28 x 0.28 | 더 넓게 부스러진 표면 자국. |
| 디컬 투영 | Depth 0.32 / Pivot (0,0,0)<br>Draw Distance 50 | 곡면 충돌 지점에서 투영 범위를 확보. |
| 탄흔 수명·방향 | 18초 / Align To Surface 켬 | 여러 발의 자국이 잠시 남고 표면 안쪽으로 투영. |
| 렌더링 | URP Decal Feature / HDR 켬<br>원본 Global Volume 유지 | 교수자 배경의 조명과 후처리를 유지하면서 디컬 표시 지원. |

### 연결과 선택 이유

Bullet 태그의 총알 -> 감지 Trigger -> Actor_Instantiate 목록 -> 피탄 프리팹과 디컬 프리팹을 함께 생성한다. 본체 SphereCollider와 로컬 반경 0.85의 Trigger를 분리했다. 물리 간격 0.01초를 프로젝트에 저장하고, 총 Hold Offset을 (0, 0.4, 0.15)로 조정했다. 표면 정렬에는 수업 액터를 사용한다.

속도 32에서 0.22초 동안 이동하는 거리는 약 7.04 m다. 실제 보이는 길이는 충돌·소멸과 시점에 따라 줄어든다. 탄흔은 같은 텍스처를 사용하되 크기를 달리해 선택 도전의 재질별 자국 차이를 시도했다.
